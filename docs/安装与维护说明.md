# 真文韵（横排版）· 使用与维护说明

## 包内容

| 文件 | 用途 |
|---|---|
| `fydeRhythm-enhanced.zip` | 修改版真文韵扩展（v1.0.0）：主设置页内嵌增强开关（自动纠错、默认简繁、emoji、全半角、分号次选、方括号翻页、Tab 辅码引导、候选窗横排实验开关） |
| `万象拼音方案-在真文韵设置页导入这个.zip` | 万象拼音预编译方案包，**在真文韵的设置页里导入**，导入一次即可 |

## 安装

1. **如果之前装过任何版本的解包版真文韵：先在 chrome://extensions 里把它移除**（移除会清掉它的旧存储，避免旧配置捣乱）。
2. 解压 `fydeRhythm-enhanced.zip` → `chrome://extensions` 开发者模式 → **加载已解压的扩展程序** → 选 `fydeRhythm-enhanced` 文件夹。装好后**不要移动/重命名**该文件夹。
3. **确认版本**：扩展卡片上的版本号应显示 **1.0.0**。替换过文件夹内容后必须在扩展卡片上点一次**重新加载**（↻），否则 Chrome 继续运行旧代码。
4. 此时输入法默认是「极光拼音」，先随便打几个字——候选窗（默认竖排）、自动纠错应该已经工作。
5. **导入万象**：真文韵设置页 → 输入方案区域 → 导入预编译方案 zip → 选 `万象拼音方案-在真文韵设置页导入这个.zip` → 进度条走完（zip 约 54 MB，落盘约 130 MB）。
6. 切换到「万象拼音」：长按中/英键出方案菜单，或 `Ctrl+\`` 循环切换。
7. 设置页里「字典包」和「RIME 服务日志」两张卡片之间 → 展开**「高级选项」**（样式克隆自原版卡片，胶囊开关与原版同款） → 打开 **Tab 进入辅码反查** → 底部弹出「设置已更改」→ 点**「保存并应用」**（引擎后台重载，页面不退出）。

## 中文标点与搜狗式标点补全（本次重磅升级）

### 1. 全量标准中文标点（斜杠/顿号彻底修复）
- **斜杠 `/` 键**：直接输出 **`、`**（顿号）！打拼音如 `zhen/` 自动上屏“真、”！
- **反斜杠 `\` 键**：直接输出 **`、`**（顿号）！无论习惯按哪个键，都是标准的中文顿号！
- **货币符号 `$` (Shift+4)**：标准全角 **`￥`**（人民币符号）！
- **波浪号 `~` (Shift+`)**：标准全角 **`～`**！
- **星号 `*` (Shift+8)**：提供常用间隔号 **`·`**（如“奥黛丽·赫本”）与 **`×`**（乘号）！
- **问号 `?` (Shift+/)**：标准全角 **`？`**！
- **省略号 `^` (Shift+6)**：标准全角 **`……`**！
- **破折号 `_` (Shift+-)**：标准全角 **`——`**！

### 2. 搜狗输入法同款【成对标点自动补全】（默认开启）
- **输入左标点自动补全右标点，光标直接落在中间**：
  - 按 `<` (Shift+,)：自动补齐 **`《》`**，光标落在中间：`《|》`
  - 按 `[`：自动补齐 **`【】`**，光标落在中间：`【|】`
  - 按 `(` (Shift+9)：自动补齐 **`（）`**，光标落在中间：`（|）`
  - 按 `"` (Shift+')：自动补齐 **`“”`**，光标落在中间：`“|”`
  - 按 `'`：自动补齐 **`‘’`**，光标落在中间：`‘|’`
  - 按 `{` (Shift+[)：自动补齐 **`「」`**，光标落在中间：`「|」`
- **顺畅跳过右标点**：打完书名后，直接敲键盘 `>`（右书名号），光标自动平滑跳出右侧，不会重复输入！
- **成对一键删除**：如果不小心按错了左标点，直接按一次 **`Backspace`**，两边的括号/引号会**同时成对删除**，干净利落！
- **自由开关**：如果不习惯标点补全，在真文韵设置页「高级选项」中关闭【成对标点自动补全】即可。

## 辅码用法（搜狗式 Tab 辅码）

- 打拼音出现组字串（如 `zhen`）后，按 **`Tab`**：输入串变为 `zhen``，进入万象专有的辅码筛选状态。
- 接着输入偏旁部首的读音，例如 **`j`**（金字旁首字母）或 **`jin`**（金）：
  - 候选词列表中带“金/钅”偏旁的字（如“镇”、“针”）将**直接被筛选出来并排在第一位**！
  - 前面输入的拼音（zhen）完全保留，不会被清空！
- 按空格直接上屏目标字（如“镇”）。
- 其他部首示例：`mu`（木）、`shui`（水）、`cao`（草）……均为您所习惯的偏旁读音拼音，无需背字根！
- 未在打字输入时按 Tab 仍是系统的切换焦点功能。

## 更新维护

**更新万象方案**（源码 → 编译 → 重打 zip → 删旧导新）：

```bash
git clone --depth 1 https://github.com/amzxyz/rime_wanxiang.git
# librime 工具（rime_deployer）从官方 release 下载
cp -r dicts lua opencc default.yaml custom_phrase.txt wanxiang*.yaml wanxiang*.dict.yaml <构建目录>/
dist/bin/rime_deployer.exe --build <构建目录> <构建目录>
# build/ 里取 wanxiang.schema.yaml + 各 .bin（不要 default.yaml 和其他 .schema.yaml）
# 之后用本仓库 scripts/build-import-zip.cjs 重新打包并校验
```

**更新扩展**：商店发新版后重新下载 CRX → 解包 → 跑本仓库 `scripts/patch-final.js` → 重压缩。

## 已知取舍

1. **候选窗横排的来龙去脉**：原版横排被 Chromium 平台 bug 阻塞（issue 469901669）——`chrome.input.ime` 把候选窗设为横排（vertical:false）时，候选词文本按 0 像素测量导致**文字不显示**，这也是真文韵作者只留竖排的原因。本版通过**把候选词文本改由 annotation 字段渲染**绕开了该缺陷，并将横排作为**实验选项**放进「高级选项」（默认仍为竖排），已在测试机型上实测可用。若个别应用内横排候选不显示，切回竖排即可；也可用 ChromeOS **浮动虚拟键盘**（真文韵自绘横排候选界面，设置 → 语言和输入法 → 屏幕键盘开启后切浮动模式）作为替代。
2. **万象为“精简 Lua 辅码稳定版”**：仅保留核心的 `super_lookup` 辅码筛选滤镜（负责反查辅码筛选，自包含且在真文韵 WASM 环境下完美运行），其余 20 多个依赖复杂系统的附加 Lua 脚本已剥离以确保引擎极速、稳定不崩溃。带调词库、中英混输、简繁、emoji、辅码筛选全部完整。
3. **万象无语法模型**：`wanxiang-lts-zh-hans.gram` 400 MB，超出真文韵 VFS 单文件 100 MB 上限，且缺失时引擎可能加载失败，因此本包已把方案的 grammar 段剥掉。影响：超长句组句略弱。
4. **custom_phrase.txt（万象自定义短语）不可用**：需放在用户目录根，导入通道到不了。用真文韵自带「词库导入」替代。
5. **Tab 辅码引导仅在万象方案下开启**：其他方案没有反查设计，开着会在组字时插入 ` 字符。
6. 万象是带声调词库，候选习惯与极光/雾凇略不同，适应期正常；不合适随时切回。
7. **增强设置的位置**：注入在真文韵设置页**「字典包」与「RIME 服务日志」卡片之间的「高级选项」卡片**，样式克隆原版卡片与胶囊开关；点「保存并应用」走后台引擎重载，**页面不会再退出**。

## 出问题怎么报

- 输入法完全不工作 / 万象激活失败：真文韵设置页底部有 **RIME 日志**查看入口（或 `chrome://extensions` → 该扩展 → 「服务工作者」点开看红色报错），截图发我。
- 横排候选窗定位异常：万象正常后直接描述现象即可。
